افزودن تأیید اجباری و جمع‌وجورِ مشاهده تاریخ انقضا پیش از افزودن کالا به سبد خرید.

== توضیحات ==
این افزونه یک چک‌باکس تأیید مشاهده تاریخ انقضا را به صفحه محصول ووکامرس اضافه می‌کند. مشتری تا زمانی که این گزینه را تأیید نکند، نمی‌تواند محصول را به سبد خرید اضافه کند.

== نصب ==
1. فایل ZIP افزونه را از بخش «افزونه‌ها ← افزودن افزونه تازه ← بارگذاری افزونه» نصب کنید.
2. افزونه «تأیید تاریخ انقضا برای ووکامرس» را فعال کنید.
3. تأیید به‌صورت پیش‌فرض برای تمام محصولات فعال است.

== غیرفعال کردن برای یک محصول ==
محصول را ویرایش کنید. در بخش «اطلاعات محصول ← همگانی»، گزینه «تأیید تاریخ انقضا» را روی «غیرفعال برای این محصول» قرار دهید و محصول را ذخیره کنید.

== سازگاری ==
برای قالب WoodMart و افزودن به سبد خرید Ajax طراحی شده است. برای جلوگیری از دور زدن تأیید، دکمه خرید سریع در فهرست محصولات، مشتری را به صفحه محصول هدایت می‌کند.

== نیازمندی‌ها ==
* وردپرس 6.0 یا جدیدتر
* ووکامرس 7.0 یا جدیدتر
* PHP 7.4 یا جدیدتر
